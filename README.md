# _sepragame_

Game of critters.

## Setup

1. Ensure that _MongoDB_ and _Node.js_ are installed.
   - _MongoDB_ is currently required to be configured on default ports/auth. This will be addressed.
2. Copy `example.start.js` to `start.js` and configure it.
3. Ensure _pnpm_ is installed by using `corepack enable`.
4. Install dependencies using `pnpm install`.
5. Start it? Mileage may vary...
